## 🚀 Introduction

**Awise Navigation** is a modern, lightweight navigation platform designed to provide a seamless browsing experience. Built with performance in mind using **SolidJS** and **Vite**, it offers fast load times and smooth interactions. The backend is powered by **Python (Flask)**, handling search tracking, data analytics, and book information retrieval efficiently.

Whether you're looking for a quick search tool or exploring curated content, Awise Navigation has you covered! ✨

## 🛠️ Tech Stack

This project leverages a robust set of technologies to ensure scalability and performance:

### 🎨 Frontend
- **Framework**: [SolidJS](https://www.solidjs.com/) (Reactive & Efficient)
- **Build Tool**: [Vite](https://vitejs.dev/) (Lightning fast HMR)
- **Rendering**: Server-Side Rendering (SSR) with Express
- **HTTP Client**: Axios

### 🔙 Backend
- **Language**: Python 🐍
- **Web Framework**: [Flask](https://flask.palletsprojects.com/)
- **ORM**: SQLAlchemy (Database Interaction)
- **Security**: JWT (JSON Web Tokens) & CORS support

---

## 🌟 Features

- **⚡ Blazing Fast**: Powered by SolidJS's fine-grained reactivity.
- **🔍 Smart Search**: Integrated search functionality with historical tracking.
- **📚 Content Discovery**: Features for book information and essay retrieval.
- **📱 Responsive Design**: Optimized for various screen sizes.

## 🔧 Getting Started

### Prerequisites
- Node.js (v16+)
- Python (3.8+)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-repo/awisenavigation.git
   ```

2. **Frontend Setup**
   ```bash
   cd awisenavigation
   npm install
   npm run dev
   ```

3. **Backend Setup**
   ```bash
   cd awisenavigation-webback
   pip install -r requirements.txt
   python app.py
   ```
