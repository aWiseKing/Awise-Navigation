## 🚀 项目简介

**Awise Navigation (智慧导航)** 是一个现代化的轻量级导航平台，旨在提供流畅的浏览体验。本项目基于高性能的 **SolidJS** 和 **Vite** 构建，确保了极快的加载速度和丝滑的交互体验。后端采用 **Python (Flask)** 驱动，高效处理搜索记录追踪、数据分析以及书籍信息检索等功能。

无论您是需要快速搜索工具，还是探索精选内容，Awise Navigation 都能满足您的需求！✨

## 🛠️ 技术栈

本项目采用了强大的技术组合，以确保系统的可扩展性和高性能：

### 🎨 前端 (Frontend)
- **框架**: [SolidJS](https://www.solidjs.com/) (响应式且高效)
- **构建工具**: [Vite](https://vitejs.dev/) (闪电般的热更新)
- **渲染方式**: 服务端渲染 (SSR) / Express
- **HTTP 客户端**: Axios

### 🔙 后端 (Backend)
- **编程语言**: Python 🐍
- **Web 框架**: [Flask](https://flask.palletsprojects.com/)
- **ORM**: SQLAlchemy (数据库交互)
- **安全**: JWT (JSON Web Tokens) & CORS 跨域支持

---

## 🌟 功能特性

- **⚡ 极速体验**: 得益于 SolidJS 细粒度的响应式机制。
- **🔍 智能搜索**: 集成了搜索功能及历史记录追踪。
- **📚 内容发现**: 提供书籍信息和文章检索功能。
- **📱 响应式设计**: 完美适配各种屏幕尺寸。

## 🔧 快速开始

### 前置要求
- Node.js (v16+)
- Python (3.8+)

### 安装步骤

1. **克隆仓库**
   ```bash
   git clone https://github.com/your-repo/awisenavigation.git
   ```

2. **前端设置**
   ```bash
   cd awisenavigation
   npm install
   npm run dev
   ```

3. **后端设置**
   ```bash
   cd awisenavigation-webback
   pip install -r requirements.txt
   python app.py
   ```
